# محكمة القرارات التربوية ⚖️

تجربة سينمائية تعليمية تفاعلية لطلبة الدراسات العليا: جلستان، 14 قضية، مداولات تتغير وفق اختيار القاضي، وعودة آمنة إلى المشاهد السابقة.

## تشغيل
افتح [المحكمة](https://fayednuha-wq.github.io/educational-court/) بعد تفعيل GitHub Pages من إعدادات المستودع.

## صوت خالد
تم تجهيز وربط **18 مسارًا صوتيًا** لخالد في المشغل:
- افتتاح وختام كل جلسة (4)
- سرد الوقائع في 14 قضية

**تنبيه مهم:** مسارات التشغيل جاهزة، لكن ملفات MP3 الثنائية يجب أن تُرفع إلى مجلد `audio/khalid/` حتى يعمل الصوت. الأسماء الحالية للملفات المرسلة إلى المحادثة تنتهي بـ `.mp3.mp3`، والمشغل مُهيأ لها دون تغيير الاسم. [مجلد رفع التسجيلات](https://github.com/fayednuha-wq/educational-court/upload/main/audio/khalid).

بعد رفع الملفات، يعرض الموقع النص اعتمادًا على زمن تشغيل التسجيل الفعلي، ويواصل إلى الحكم عند انتهاء التسجيل (وليس بمؤقت مستقل). توقيت انتقال *الفقرات* تقديري وموزع وفق طولها؛ دقة محاذاة كل كلمة تحتاج توقيتات صوتية/مواءمة خاصة.

أُلغي ملف الافتتاح التجريبي المضمن لمنع التكرار.

## التنقل والتقويم
- السابق والتالي أثناء مشاهدة المرافعات والمداولات.
- الرجوع من شاشة الاختيارات لإعادة مراجعة القضية.
- الحكم الصحيح محفوظ؛ المراجعة لا تسبب انسداد التقدم ولا احتساب الخطأ مرتين.
- مؤثرات صوتية محلية عند الحكم الصحيح والخاطئ، مع زر لكتمها.
- مداولات كريم وفيصل وحامد نصية حتى تُضاف تسجيلاتها لاحقًا.

**مهم:** رفع ملفات الصوت أو تعديل هذا المستودع لا يغيّر أيًا من مستودعات المشاريع التعليمية الأخرى.
