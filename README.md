# محكمة القرارات التربوية ⚖️

محاكاة تعليمية تفاعلية لطلبة الدراسات العليا، تضم جلستين و14 قضية مستمدة من الوثيقتين المرفقتين بالمشروع الأصلي.

## التشغيل
افتح `index.html` أو شغّل الموقع عبر GitHub Pages.

## طريقة اللعب
- خالد يعرض وقائع القضية، ويستطيع المتعلم استخدام **التالي**.
- يتوقف العرض عند أربعة أحكام؛ يمكن استخدام **عودة إلى القضية**.
- عند الحكم الخاطئ تتداول اللجنة ويتاح التنقل **السابق / التالي** بين المستشارين.
- عند الحكم الصحيح يسمع المتعلم مؤثر المطرقة ويتقدم إلى القضية التالية.

## الأصوات
تحتوي النسخة على عينة افتتاحية بصوت خالد عند توفرها. أما قراءة القضايا ومداولات المستشارين، فتعتمد على عرض النصوص حتى تُضاف التسجيلات الأصلية لكل دور. **المؤثرات الصوتية مولدة داخل المتصفح دون خدمة مدفوعة** ولا تستخدم صوت القراءة الاصطناعي للجهاز.

## الخصوصية
نسخة ثابتة تعمل دون خادم أو حساب للطالب. يمكن كتم المؤثرات.
